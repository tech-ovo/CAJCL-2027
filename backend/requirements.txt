# The CURRENT Turso driver. Not `libsql-client`, which was archived in June 2025
# and whose WebSocket handshake is rejected by present-day Turso endpoints --
# see the comment in backend/lib/db.py.
#
# THE MARKER IS DELIBERATE. libsql publishes wheels for x86_64 Linux, both macOS
# architectures, and x86_64 Windows -- but for NO ARM platform except macOS.
# Everywhere else on ARM, pip falls back to compiling it from Rust source, which
# needs cmake and a full toolchain and usually fails.
#
# Two ARM cases are excluded here:
#   aarch64          ARM Linux, which is what WSL is on a Snapdragon laptop
#   win32 + ARM64    Windows itself on the same laptop
# macOS on Apple silicon reports `arm64` and DOES have a wheel, so it is left in.
#
# Nothing local needs this driver: a local .db file uses `sqlite3` from the
# standard library. It is needed only to reach a hosted Turso database, and
# Modal's image is x86_64, so production installs it normally. If you are on
# ARM and want to reach Turso from your own machine, see docs/RUNBOOK.md --
# the short answer is `modal run backend/app.py::setup`.
# (Marker syntax has no `not`, hence the or-form of "neither of those two".)
libsql; platform_machine != "aarch64" and (sys_platform != "win32" or platform_machine != "ARM64")

segno

# The IANA time-zone database, as a Python package.
#
# `zoneinfo` reads the operating system's copy. Linux and macOS ship one;
# WINDOWS DOES NOT, and neither does every slim container base. Without this,
# `ZoneInfo("America/Los_Angeles")` in clock.py raises ZoneInfoNotFoundError at
# import time -- so the whole application, the test suite, and every script fail
# before doing anything, on a fresh Windows checkout.
#
# It is declared unconditionally rather than with a `sys_platform == "win32"`
# marker on purpose. A marker would leave the Linux side depending on whatever
# the base image happens to ship, which is exactly the kind of thing that works
# for a year and then does not. 350 KB buys the same behaviour everywhere.
#
# Every deadline in this system is "end of day in California". See clock.py.
tzdata

# Pure Python and adds nothing measurable to a cold start, so an export can be
# produced inline rather than waiting for the fat image to boot.
openpyxl
